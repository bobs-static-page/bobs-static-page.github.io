Welcome to Static Pages!

A site built with just plaintext and images

My solution to the neverending digital world that changes on its own whim

Is this freely hosted and simply designed static website

Built with nothing but HTML and CSS - no JS, no Stacks, no Pipelines.

The goal of this project is somewhere that I can host a variety of items:
A place to store my recipes, to talk about my thoughts, and to list my natural perfumes I've developed.

The layout of this site will be similar a physical broadsheet - soft colours and easy to read text

To keep my design plans basic, consistent, and deliverable, the CSS behind this site is aimed to be scalable with content and viewports/screenszies.

Below will be some sizing, ratios, and design choices for the site - freely viewable from Git or global.css

Colours:
Background is Floral White
Font is Dark Slate Grey

Fonts:
Body - Courier (monospace)
Headers - Tahoma (sans-serif)

Font size rule:
Scaled to 0.6 of 16px at minimum
Preferred 0.8% of the view + 16px
At most scaled to 1.2 of 16px

H 1-3: Scaled to font size rule at 1.5 -0.5 per heading

Footer: Scaled to 0.8 of 16px
Menu: Scaled to font size rule at 1.3
Centered sections: scaled to 1.2 of 16px
Continuous sections: Scaled to 0.9 of 16px

View:
Wide screens are 65%
Narrow screens are 80%
